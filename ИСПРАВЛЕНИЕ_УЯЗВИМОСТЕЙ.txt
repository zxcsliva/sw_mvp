  ИСПРАВЛЕНИЕ УЯЗВИМОСТЕЙ (опционально)
═══════════════════════════════════════════════════════════════

Уязвимости в dev-зависимостях обычно не критичны для разработки.
Но если хотите их исправить:

1. ОБНОВИТЕ ЗАВИСИМОСТИ:
   npm update

2. ИЛИ ИСПРАВЬТЕ АВТОМАТИЧЕСКИ:
   npm audit fix

3. ЕСЛИ НУЖНО ПРИНУДИТЕЛЬНОЕ ИСПРАВЛЕНИЕ (может сломать что-то):
   npm audit fix --force

═══════════════════════════════════════════════════════════════

ВАЖНО: Уязвимости в dev-зависимостях не влияют на production сборку.
Для продакшена используйте: npm run build
