  ИНСТРУКЦИЯ ПО УСТАНОВКЕ И ЗАПУСКУ ПРОЕКТА
═══════════════════════════════════════════════════════════════

1. ОТКРОЙТЕ POWERSHELL ОТ ИМЕНИ АДМИНИСТРАТОРА
   (Правый клик на PowerShell → "Запуск от имени администратора")

2. ПЕРЕЙДИТЕ В ПАПКУ ПРОЕКТА:
   cd C:\Users\zxslivasx\Desktop\moskal_refactor\smart-home-landing

3. ЕСЛИ ВОЗНИКНЕТ ОШИБКА С ПОЛИТИКОЙ ВЫПОЛНЕНИЯ, ВЫПОЛНИТЕ:
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser
   (Нажмите Y и Enter)

4. УСТАНОВИТЕ ЗАВИСИМОСТИ:
   npm install

5. ЗАПУСТИТЕ ПРОЕКТ:
   npm run dev

6. ОТКРОЙТЕ БРАУЗЕР:
   http://localhost:3000

═══════════════════════════════════════════════════════════════

АЛЬТЕРНАТИВНЫЙ СПОСОБ (если npm install не работает):

1. Откройте PowerShell от имени администратора
2. Выполните:
   .\install.ps1

═══════════════════════════════════════════════════════════════

ВСЕ ГОТОВО! Проект должен работать красиво и без ошибок.

Если что-то не работает - проверьте:
- Node.js установлен (node --version)
- npm установлен (npm --version)
- Все файлы на месте
